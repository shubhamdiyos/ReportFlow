Objective:
Enhance the existing GitHub Reporting Tool frontend by adding a Report Generation Wizard and improving the Reports Page with Details and Charts tabs.

1. Report Generation Wizard (Modal / Stepper)

Triggered by:

"Generate Report" button on Dashboard.

"Generate Report" button on Reports Page.

Step 1: Select Report Type

Options: Developer Report, Team Report, Organization Report

Radio buttons with description under each.

Step 2: Select Time Period

Predefined options: This Month, Last Month, Custom Range.

Date picker for custom.

Step 3: Select Repositories & Contributors

Multi-select dropdown for repositories.

Multi-select for contributors (fetch from GitHub org users).

Show badges for selected items.

Step 4: Confirmation

Summary of selections (type, period, repos, contributors).

"Generate Report" button (primary CTA).

UI Specs:

Use Stepper UI (shadcn/ui or custom).

Show progress indicator at top (Step 1 → 4).

Close button (top-right).

Loading state after final confirmation.
